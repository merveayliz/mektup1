## 📖 Proje Hakkında / About
**TR:** Mektup1, özel mesajları, duygusal anlatımları ve nostaljik mektup konseptini modern web tasarımıyla harmanlayan, kullanıcıya anlamlı bir deneyim sunan özgün bir frontend web projesidir.

**EN:** Mektup1 is a unique frontend web project that blends special messages, emotional expressions, and the nostalgic letter concept with modern web design, offering users a meaningful experience.

---

## ✨ Özellikler / Key Features
- 📜 **Nostaljik & Modern Konsept / Nostalgic & Modern Concept:** Geleneksel mektup hissiyatını modern web trendleriyle buluşturan zarif tasarım. / Elegant design blending traditional letter feelings with modern web trends.
- 🎨 **Duygusal Atmosfer / Emotional Atmosphere:** İç açıcı, sakin ve içeriğin ruhunu yansıtan renk ve tipografi seçimi. / Color and typography selection that is welcoming, calm, and reflects the spirit of the content.
- 📱 **Tam Duyarlı / Fully Responsive:** Mobil ve masaüstü ekranlarda kusursuz görüntüleme uyumu. / Flawless viewing compatibility on mobile and desktop screens.
- ✨ **Dinamik Dokunuşlar / Dynamic Touches:** JavaScript ile desteklenen akıcı sayfa içi etkileşimler. / Smooth in-page interactions powered by JavaScript.

---

## 🛠️️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Semantik web yapısı / Semantic web structure
* **CSS3:** Stil yönetimi, özel geçişler ve esnek tasarım / Styling, custom transitions, and flexible design
* **JavaScript:** Sayfa içi dinamik özellikler / In-page dynamic features
